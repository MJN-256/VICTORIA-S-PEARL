# Victoria's Tours & Travel

A simple travel and tours website for discovering Uganda and planning local trips.

## Languages

The website includes English, French, Spanish, German, Turkish, Swahili, Luganda, and Arabic. It selects a supported language from the visitor's browser preferences, and visitors can choose another language from the header. A manual choice is saved in the browser for future visits.

For languages not in the selector, visitors can use their browser's built-in translation feature. The page's language metadata is updated when a supported language is selected to help assistive technologies and browser translation tools.
